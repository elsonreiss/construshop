## 📡 36 ENDPOINTS REST

```
GET    /api/products                    - Listar produtos
GET    /api/products/{id}               - Detalhe produto
POST   /api/products                    - Criar produto
PUT    /api/products/{id}               - Atualizar produto
DELETE /api/products/{id}               - Deletar produto

GET    /api/categories                  - Listar categorias
GET    /api/categories/{id}             - Detalhe categoria
POST   /api/categories                  - Criar categoria
PUT    /api/categories/{id}             - Atualizar categoria
DELETE /api/categories/{id}             - Deletar categoria

GET    /api/users                       - Listar usuários
GET    /api/users/{id}                  - Detalhe usuário
POST   /api/users                       - Registrar usuário
PUT    /api/users/{id}                  - Atualizar usuário
DELETE /api/users/{id}                  - Deletar usuário

GET    /api/addresses/user/{userId}     - Endereços do usuário
GET    /api/addresses/{id}              - Detalhe endereço
POST   /api/addresses                   - Criar endereço
PUT    /api/addresses/{id}              - Atualizar endereço
DELETE /api/addresses/{id}              - Deletar endereço

GET    /api/cart/{userId}               - Obter carrinho
POST   /api/cart                        - Adicionar item
PUT    /api/cart/items/{id}             - Atualizar quantidade
DELETE /api/cart/items/{id}             - Remover item
DELETE /api/cart/{userId}/clear         - Limpar carrinho

GET    /api/orders                      - Listar pedidos
GET    /api/orders/{id}                 - Detalhe pedido
GET    /api/orders/user/{userId}        - Pedidos do usuário
POST   /api/orders/checkout             - Finalizar compra
PATCH  /api/orders/{id}/status          - Atualizar status
PATCH  /api/orders/{id}/cancel          - Cancelar pedido
```

## 💡 COMO USAR

### 1. Iniciar Desenvolvimento
```bash
cd C:\Users\elson\Downloads\construshop
.\mvnw.cmd spring-boot:run --no-transfer-progress
```

### 2. Acessar
- API: http://localhost:8080
- H2: http://localhost:8080/h2-console (sa / sem senha)

### 3. Testar
- Importar **POSTMAN_COLLECTION.json** no Postman
- Ou executar **API_EXAMPLES.sh** (bash)
- Ou usar curl manualmente

### 4. Docker (Produção)
```bash
docker-compose up -d
```
